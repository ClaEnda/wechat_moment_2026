# 电脑微信浏览朋友圈

导出前，先在微信里自己打开要看的朋友圈窗口。程序只滚动这个已经打开的窗口，不会自己搜索好友。

## 一、所有人的朋友圈

1. 在微信里打开自己的朋友圈。
2. 回到本工具，点「自动浏览当前朋友圈」，再点「开始」。
3. 滚到需要的日期后，点「下一步」复制数据。

朋友圈窗口没打开时，工具会提示「请先在微信里打开朋友圈窗口」。

## 二、某一个人的朋友圈

1. 在微信里自己打开那个人的朋友圈。
2. 回到本工具，点「自动浏览当前朋友圈」，再点「开始」。
3. 滚完后点「下一步」。导出页再勾选这个联系人。

这一步不会按昵称去搜一搜。窗口里没有被滚到的内容，仍然不会进入导出。
